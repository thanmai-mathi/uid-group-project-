Digital Humanity FootPrint is an interactive and educational web project 
developed as a User Interface Group Project by our team of four members 
Thanmai.M [AM.SC.U4CSE25331] , Harshita.S [AM.SC.U4CSE25322] , Neekshitha.Ch [AM.SC.U4CSE25311]
and Sagar.A [AM.SC.U4CSE25303].The main objective of this project is to present the 
complete journey of humanity in a visually immersive and engaging way through modern 
web technologies.The website explores various topics such as the origin of the universe, 
the Big Bang,the formation of earth and the evolution of human civilization,inventions,
historical timelines,and the growth of human knowledge across different eras. By combining 
educational content with creative storytelling and interactive design,the project aims to 
make learning more interesting,memorable,and accessible for users of all age groups.

The Website was designed and developed using HTML,CSS,and JavaScrpit,with special
attention given to responsive layouts,smooth navigation,custom animations,interactive
timelines,and visually appealing backgrounds that match the theme of each page .
Multiple interconnected pages were created to organize the content effectively and 
provide users with a seamless browsing experience. the project also includes
animated effects,hover interactions,customized styling,and structured navigation
syste,s to improve user engagement and overall usability.


Throughout the development process,the project helped our team strengthn important 
technical and collaborative skills such as frontend web development,UI/UX design,
file organisation,responsive web design,debugging,teamwork,and large-scale multi-page 
websites are planned and connected and deployed successfully.Digital humanity footprint
not only reflects our creativity and meaningful digital platform that combines 
education, technology,history, and visual storytelling into one unified web experience.
